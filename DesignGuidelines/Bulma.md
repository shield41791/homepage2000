# 쭈요네 홈페이지 — 디자인 가이드

2000년대 초반 개인 홈페이지(GeoCities / 부르마의 드래곤볼 류 팬사이트) 감성을 현대 웹으로 재현한 개인 디지털 아카이브. "옛날 디자인 흉내"가 아니라 **그 시절 브라우저 안에서 보이던 웹사이트의 분위기와 사용 경험**을 되살리는 것이 목표.

---

## 1. 컨셉 & 톤

- **레퍼런스 우선순위**: bulma(부르마의 드래곤볼) 스크린샷 > 기타 2000년대 팬사이트.
- **핵심 원칙**
  - **당시 브라우저 안 웹사이트**의 룩을 따른다.
  - 화면 전체를 쓰는 **풀블리드(full-bleed)** 레이아웃. 배경과 분리된 카드형 컨테이너를 쓰지 않는다.
  - 일부러 **어설프게**: 정렬 제각각, 요소 배치 투박, 가끔 가독성이 완벽하지 않은 옛 감성 유지.

---

## 2. 컬러 팔레트 (파스텔 블루톤)

메인 컬러는 파스텔 블루. 포인트로 게시판 그린과 LCD 그린을 함께 쓴다. (한 화면에 배경색 1~2개 원칙)

| 용도 | HEX |
| --- | --- |
| 링크 기본 | `#2f6ab0` |
| 링크 hover | `#3399dd` |
| 배너 그라디언트 | `#e1f0ff` → `#b9dcff` |
| 배너/구분선 보더 | `#4d9fe6` |
| 프레임 헤더 배경 | `#dfeeff` |
| 프레임 헤더 글자 / 강조 제목 | `#0d5fc0` |
| 프레임 이중선 보더 (바깥/안) | `#6a95c7` / `#c9e4ff` |
| 본문 텍스트 | `#333` / 보조 `#444`,`#777` |

## 3. 타이포그래피

의도적으로 여러 옛 한글 폰트를 섞어 당시 느낌을 낸다.

- **본문/UI**: `굴림(Gulim)`, `돋움(Dotum)`
- **제목/헤더 강조**: `궁서(Gungsuh)` 계열 serif
- **로고/환영 문구**: `Comic Sans MS`
- **카운터·시계·모노 정보**: `돋움` monospace 느낌
- 최소 크기: 본문 12px, 캡션 9~11px (레트로 감성상 작게 허용).

---

## 4. 레이아웃 시스템

`<table>` 기반 프레임셋 레이아웃 (당시 방식 재현).

```
┌──────────────────────────────────────────────┐
│  배너 (로고 + zzuyo.wo.to)                     │
│  · ∘ · ∘ 점선 구분줄 · ∘ · ∘                    │
│  ▶ 마퀴(흐르는 공지) ◀                          │
├───────────┬──────────────────────────────────┤
│ 사이드바   │  콘텐츠 (페이지별)                  │
│ (172px)   │                                   │
│ ·미니홈    │                                   │
│ ·메뉴그룹  │                                   │
│ ·LCD카운터 │                                   │
│ ·best view │                                   │
├───────────┴──────────────────────────────────┤
│  풋터바: BGM 플레이어 · [화면효과 설정] · ⓒ     │
└──────────────────────────────────────────────┘
     (우측 고정 파스텔블루 별무늬 스트립)
```

- **이중선 보더**가 핵심 포인트: 바깥 `2px solid #6a95c7` + `padding:1px` + 안쪽 `1px solid #c9e4ff`. 강조 프레임은 `3px double`.
- 사이드바 메뉴는 **MENU(대문·프로필) / 자료실(프로젝트·사진첩·미디어) / 커뮤니티(게시판·방명록·링크)** 3개 그룹 박스로 묶고, 링크는 **우측 정렬**(bulma 방식), 현재 페이지는 테두리 박스로 표시.
- 사이드바 상단엔 미니홈 프로필 박스, 하단엔 LCD 카운터 + best view 안내.
- 이미지 자리는 45도 줄무늬 플레이스홀더 + `[설명]` 라벨.

## 5. 사이트 구조 & 페이지 구성

사이트 구조: **대문 · 홈 · 프로필 · 공지사항 · 게시판 · 사진첩 · 동영상 · 프로젝트**

- **대문** — 밝은 흰 배경의 독립 진입 페이지. 대문 이미지 + 환영 문구 + ENTER 버튼(클릭 시 홈으로) + 방문자 카운터(오늘/총). "요즘은 의미 없지만 당시 감성"용.
- **홈** — 진입 시 첫 화면. 간단한 소개글+이미지 + 각 게시판(공지/자유/개발일지)의 **최신글 모음**(클릭 시 해당 글로 이동).
- **프로필** — 사진, 자기소개, 관심사, 좋아하는 것들, SNS 링크.
- **공지사항 / 게시판** — bulma 그린 스타일 목록(NO·SUBJECT·NAME·DATE·HIT) → 상세. 게시판은 카테고리 탭(자유/일기/여행기/개발일지). ✿ 줄, [1][2][3] 페이징, TODAY/TOTAL LCD.
- **사진첩** — 탭 **ALL / 사진 / 일러스트 / 웹툰 / 스크린샷**, 그리드 썸네일 → 클릭 시 상세 페이지(게시판과 동일 형식, 이미지는 `<img>` 태그로 삽입).
- **동영상** — 그리드 썸네일 → 클릭 시 유튜브 영상이 다이얼로그(모달 iframe)로 재생.
- **프로젝트** — 그리드 썸네일 → 클릭 시 **새 탭**에서 링크(제작 사이트/깃허브)로 이동.

**NEW 표시**: 새 글이 있는 메뉴/카테고리/항목 옆에 `[N]`(빨강) 배지.

**편집 기능 제외**: 게시판/사진첩 등의 글쓰기·편집은 홈페이지에 없음. 편집은 별도 CMS에서 처리(홈페이지는 읽기 전용).

## 6. 인터랙션 / 이펙트 (풀 레트로)

- **마우스 꽁무니(트레일)** 파티클 — 유지 (커서 이미지 교체는 하지 않음)
- **클릭 시 스파클** 버스트
- **날씨 파티클**: 눈 / 벚꽃 / 낙엽 / 비 — 화면효과 설정에서 선택
- **마퀴**(흐르는 텍스트) 공지 + BGM 곡명
- **BGM 플레이어**: UI 껍데기만 (재생/음소거 아이콘, 회전 디스크). 실제 음원 재생 없음
- **방문자 카운터**: 그럴듯한 고정 숫자 (누적 004231 / 오늘 128)
- **실시간 시계**: 현재 시각 표시
- **화면효과 설정 패널**: 효과 선택 + "효과 줄이기(접근성)" 토글. 선택값 localStorage 저장
- `reduce motion` 켜면 파티클/트레일/스파클 정지

## 7. 반응형 / 디바이스

- **PC**: 데스크탑 고정폭. 해상도와 무관하게 레트로 레이아웃 그대로.
- **모바일(≤600px)**: 피처폰 목업이 아니라 **PC 레트로 웹사이트를 그대로 좁은 1단으로 재해석**. 같은 시각 언어(파스텔 블루 배너, 마퀴, 이중선 프레임, LCD 카운터, 게시판 그린 표) 유지. 사이드바 → 가로 스크롤 메뉴바, 2열 → 1열 스택.

---

## 8. 하지 말 것 (Anti-patterns)

- Windows 98 등 OS 크롬(타이틀바, 최소화/닫기 버튼, 작업표시줄) 차용 금지
- 배경과 분리된 둥근 카드 컨테이너 / 그림자 남발 금지
- 스톡 아이콘·이모지 아이콘 세트 (당시엔 아이콘 이미지 구하기 어려웠음) 금지
- 지나치게 깔끔·정돈된 정렬 (레트로 감성 훼손)
