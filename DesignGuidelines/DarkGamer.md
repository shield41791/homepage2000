# 칠흑's 다크로드 — 디자인 문서

2000~2004년경 국내 개인 홈페이지(개인 게임 팬사이트) 감성을 의도적으로 조악하게 재현한 사이트.
"세련되게 재해석"이 아니라 "당시의 투박함 자체"를 목표로 함.

## 레퍼런스
- **References/DarkGamer** (메인 레퍼런스): 검정 배경 온라인게임 팬사이트. 전체 톤/구조의 기준.
- **References/Bulma**: 게시판·공지사항 테이블 레이아웃(번호/제목/이름/날짜/조회, 공지 고정행, 좌측 텍스트 메뉴) 참고.
- **References/Gray, Girlish**: 배너·버튼 스타일 등 부분 참고.
- 브라우저 자체 UI(IE 크롬 등)는 참고 대상 아님. 웹페이지 콘텐츠만 반영.

## 사이트 구조 (homepage2000/common-structure.md 기준)
대문 → 홈 → 프로필 / 공지사항 / 게시판 / 사진첩 / 동영상 / 프로젝트
공통 헤더(로고 배너+상단 마퀴)·좌측 메뉴·하단 고정 공지 티커를 모든 내부 페이지에서 공유.

## 파일 구성
- `Entrance.dc.html` — 대문(스플래시): 로고, 환영문구, ENTER 버튼, 방문자 카운터, BGM 표시
- `Home.dc.html` — 홈: 최근 게시글/공지 2단, 배너모음, 로그인 박스
- `Profile.dc.html` — 프로필: 사진, 자기소개, 관심사, 좋아하는 것, SNS 링크
- `Notice.dc.html` — 공지사항: 게시판형 테이블, 공지 고정행
- `Board.dc.html` — 게시판: 자유/사냥터정보/거래 탭
- `Photos.dc.html` — 사진첩: ALL/사진/일러스트/웹툰/스크린샷 탭 + 그리드
- `Videos.dc.html` — 동영상: 그리드 → 클릭 시 재생 다이알로그
- `Projects.dc.html` — 프로젝트: 그리드 → 클릭 시 새 탭 이동(placeholder)
- `PostView.dc.html` — 게시판/공지/사진첩 공용 상세 페이지 (`?board=&id=`)

편집 기능(글쓰기/수정/삭제)은 포함하지 않음 — 별도 CMS 전제.

## 비주얼 스타일
- 배경: 순검정(#000). 좌측 메뉴판: 짙은 차콜(#141414) + 굵은 이중선 구분.
- 로고 배너: 네이비 플랫 컬러 + 굵은 outset 흰/하늘색 테두리, 노란 글자 + 하드 드롭섀도(그라디언트/블러 금지).
- 폰트: 바탕체/BatangChe 계열 전체 적용(세리프, 삐침 있는 국문 서체) + Times New Roman 혼용.
- 텍스트 색: 제목 노랑(#ffcc00), 링크 하늘색(#66d9ff)/hover 핑크(#ff66cc), 본문 옅은 회색, 강조 빨강/초록(터미널톤).
- 좌측 메뉴: 단색 텍스트 리스트("- 홈" 형식), 색색 구분점 없음 — 지나치게 세련된 느낌 배제.
- 상단: "어디로?" 셀렉트박스 제거, 스크롤 마퀴 티커만 유지(`<marquee>` 태그 실사용).
- 하단: 고정 공지 티커 바(네이비 라벨 + 검정 마퀴).
- 게시판류 테이블 헤더: 보라(#9900cc) 플랫 바 + 검정 굵은 테두리(Bulma 스타일 차용).
- 버튼/입력창: 그라디언트·둥근모서리·부드러운 그림자 없음. 굵은 outset/inset 테두리의 플랫 버튼.
- 이미지: 실제 자료 없어 줄무늬 placeholder + 모노스페이스 설명 문구로 대체.
- 커서: 기본 화살표(과한 커스터마이징 지양).

## 톤 & 카피
- 20대 후반 남성, 다크판타지 온라인게임("다크로드 온라인") 팬. 담백한 존댓말.
- 배너모음, 자동재생 BGM 표시, 방문자 카운터(LCD풍 검정+주황 숫자) 등 시대 특유의 장치 포함.

## 알려진 제약
- 이미지/사진/BGM 실파일 없음 — 모두 자리표시자.
- 편집·로그인·방명록 등은 UI만 존재("준비중입니다" 알림).
