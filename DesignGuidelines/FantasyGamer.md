# 실피의 아르카디아 — 디자인 문서

2000~2004년경 국내 개인 홈페이지(판타지 온라인게임 팬사이트) 감성을 의도적으로 조악하게 재현한 사이트.
"세련되게 재해석"이 아니라 "당시의 투박함 자체"를 목표로 함.

## 레퍼런스
- **References/FantasyGamer** (메인 레퍼런스, Everlore 스크린샷): 돌/양피지 톤 배경, 금색 장식 로고, 상단 탭 메뉴, 좌측 박스형 목록, 배너 광고, 룬 장식 구분선.
- **References/Bulma**: 게시판·공지사항 테이블 레이아웃(번호/제목/이름/날짜/조회) 참고.
- 브라우저 자체 UI(IE 크롬 등)는 참고 대상 아님. 웹페이지 콘텐츠만 반영.

## 사이트 구조 (homepage2000/common-structure.md 기준)
대문 → 홈 → 프로필 / 공지사항 / 게시판 / 사진첩 / 동영상 / 프로젝트
공통 헤더(배너+장식 구분선+상단 탭+광고 배너+마퀴)·좌측 박스형 메뉴·하단 고정 공지 티커를 모든 내부 페이지에서 공유.
회원가입/로그인 등 회원 시스템은 없음 — 좌측은 메뉴, 사이트 현황(게시글/사진/누적방문자 수), 방명록·즐겨찾기·사이트맵 버튼으로 구성.

## 파일 구성
- `Entrance.dc.html` — 대문(스플래시): 로고, 환영문구, ENTER 버튼, 방문자 카운터, BGM 표시
- `Home.dc.html` — 홈: 최근 게시글/공지 2단, 배너모음
- `Profile.dc.html` — 프로필: 사진, 자기소개, 관심사, 좋아하는 것, SNS 링크
- `Notice.dc.html` — 공지사항: 게시판형 테이블, 공지 고정행
- `Board.dc.html` — 게시판: 자유/사냥터정보/거래 탭
- `Photos.dc.html` — 사진첩: ALL/사진/일러스트/웹툰/스크린샷 탭 + 그리드
- `Videos.dc.html` — 동영상: 그리드 → 클릭 시 재생 다이알로그
- `Projects.dc.html` — 프로젝트: 그리드 → 클릭 시 새 탭 이동(placeholder)
- `PostView.dc.html` — 게시판/공지/사진첩 공용 상세 페이지 (`?board=&id=`)

편집 기능(글쓰기/수정/삭제)은 포함하지 않음 — 별도 CMS 전제.

## 비주얼 스타일
- 배경: 회색 돌(cracked stone) 텍스처 (`#a8a292`/`#9a9484` 교차 반복 그라디언트).
- 사이트 프레임: 800px 고정폭, 올리브그레이 패널(`#a39c88`) + 진갈색 테두리(`#4a3c1a`).
- 배너: 짙은 청록/보라 painted 텍스처 배경, 좌우 그림 placeholder(돛단배/탑), 금색 이탤릭 로고 + 하드 드롭섀도.
- 로고 밑 구분선: 금/브론즈 다이아몬드 반복 패턴(룬/체인 장식 바).
- 상단 보조 탭: 올리브-브라운 플랫 바, 금색 텍스트("지도 종족 마법서 아이템 몬스터도감 커뮤니티") — 장식용, 실제 이동은 좌측 메뉴가 담당.
- 광고 배너: 검정 배경 + 빨강 테두리 placeholder box (시대 특유의 배너광고 클러터 재현).
- 좌측 메뉴: 양피지색(`#f3ead0`) 박스 안에 목록형 메뉴, 그 아래 "사이트 현황" 박스(게시글/사진/누적방문자), 맨 아래 outset 테두리 버튼 3개(방명록/즐겨찾기/사이트맵).
- 폰트: 바탕체/BatangChe 계열 + Times New Roman 혼용(세리프).
- 텍스트 색: 헤더 브론즈-골드(`#8a6d1a`), 링크 기본 갈색(`#7a4a12`)/hover 적갈색(`#b5231f`), 현재 메뉴 진한 적갈색(`#7a1010`), 본문 진갈색(`#3a2e10`).
- 게시판류 테이블 헤더: 올리브-브론즈 플랫 바(`#6b5a1f`) + 검정 굵은 테두리(Bulma 스타일 차용).
- 버튼/입력창: 그라디언트·둥근모서리·부드러운 그림자 없음. 굵은 outset/inset 테두리의 플랫 버튼.
- 이미지: 실제 자료 없어 줄무늬 placeholder + 모노스페이스 설명 문구로 대체.
- 커서: 기본 화살표(과한 커스터마이징 지양).

## 톤 & 카피
- 20대 초반 여성, 판타지 온라인게임("아르카디아 온라인") 팬. 담백한 존댓말.
- 배너모음, 자동재생 BGM 표시, 방문자 카운터(LCD풍 검정+주황 숫자) 등 시대 특유의 장치 포함.

## 알려진 제약
- 이미지/사진/BGM 실파일 없음 — 모두 자리표시자.
- 회원 시스템 없음(로그인/가입/방명록 등록 UI 없음). 방명록·검색·사이트맵 버튼은 "준비중입니다" 알림만 표시.
