# 흑월's 테네브리스 — 디자인 문서

2000~2004년경 국내 개인 홈페이지(다크판타지 온라인게임 팬사이트) 감성을 의도적으로 조악하게 재현한 사이트.
"세련되게 재해석"이 아니라 "당시의 투박함 자체"를 목표로 함.

## 컨셉
- 주인장: 흑월, PC방 죽돌이 20대 후반 남성 회사원
- 즐기는 게임: 테네브리스 온라인 (가상의 다크판타지 MMORPG, 4년째)
- 소속 문파: 야회
- 콘텐츠: 캐릭터 키우기/직업별 공략, 문파 소식, 게임 플레이 후기·넋두리 섞인 일기

## 레퍼런스
- References/DarkGamer: 검정 배경 온라인게임 팬사이트. 전체 톤/구조의 기준.
- References/Bulma: 게시판·공지사항 테이블 레이아웃(번호/제목/이름/날짜/조회) 참고.
- 브라우저 자체 UI(IE, 크롬 등)는 참고 대상 아님. 웹페이지 콘텐츠만 반영.

## 사이트 구조 (homepage2000/common-structure.md 기준, 일부 대체)
대문 → 홈 → 프로필 / 공지사항 / 게시판 / 사진첩 / 게임가이드 / 문파정보
- "동영상" 슬롯 → 게임가이드로 대체 (직업별 공략)
- "프로젝트" 슬롯 → 문파정보로 대체 (문파소개, 지향목표/정신, 수칙, 문파원 목록)

공통 헤더(로고 배너)·상단 가로 메뉴바(테이블 기반, "홈 | 프로필 | ..." 파이프 구분)·상단/하단 마퀴 티커를 모든 내부 페이지에서 공유.

## 파일 구성
- `Entrance.dc.html` — 대문(스플래시): 로고, 환영문구, ENTER 버튼, 방문자 카운터, BGM 표시
- `Home.dc.html` — 홈: 최근 업데이트/공지 2단, 배너모음, 로그인 박스, 방명록 링크
- `Profile.dc.html` — 프로필: 사진, 자기소개, 관심사, 좋아하는 것, SNS 링크
- `Notice.dc.html` — 공지사항: 게시판형 테이블, 공지 고정행
- `Board.dc.html` — 게시판: 자유/사냥터정보/거래/일기장(넋두리) 4개 탭
- `Photos.dc.html` — 사진첩: ALL/사진/일러스트/웹툰/스크린샷 탭 + 그리드
- `GameGuide.dc.html` — 게임가이드: 직업별(전사/마법사/궁수/힐러) 공략 그리드 → 상세
- `GuildInfo.dc.html` — 문파정보: 문파소개, 지향목표&정신 표, 수칙, 문파원 목록 표
- `PostView.dc.html` — 게시판/공지/사진첩/게임가이드 공용 상세 페이지 (`?board=&id=`)

편집 기능(글쓰기/수정/삭제)은 포함하지 않음 — 별도 CMS 전제. 로그인/가입/방명록 등 버튼은 클릭 시 "준비중" 알림만 표시.

## 비주얼 스타일
- 배경: 순검정(#000).
- 로고 배너: 다크 퍼플/블랙 대각선 줄무늬 배경 + 굵은 outset 보라(#6a0dad) 테두리, 골드 글자(#ffcc00) + 하드 드롭섀도(그라디언트/블러 금지).
- 상단 메뉴바: 진한 자주(#2a0e1a) 바탕에 보라 상하 테두리, 텍스트 링크를 " | "로 구분(표 기반 마크업).
- 폰트: 바탕체/BatangChe 계열 전체 적용(세리프, 삐침 있는 국문 서체) + Times New Roman 혼용, 본문 강조는 `<font face="굴림">`.
- 텍스트 색: 제목 골드(#ffcc00), 링크 하늘색(#66ccff)/hover 핑크(#ff66cc), 본문 옅은 회색, 강조 빨강(#ff5555)/초록 터미널톤(#00ff88, 마퀴 전용).
- 게시판류 테이블 헤더: 보라(#6a0dad) 플랫 바 + 검정 굵은 테두리(Bulma 스타일 차용).
- 버튼/입력창: 그라디언트·둥근모서리·부드러운 그림자 없음. 굵은 outset/inset 테두리의 플랫 버튼, 로그인 인풋은 보라 inset 테두리.
- 이미지: 실제 자료 없어 줄무늬 placeholder(보라/검정 대각선) + 모노스페이스 설명 문구로 대체.
- 커서: 기본 화살표(과한 커스터마이징 지양).
- 아마추어 마크업: `<table>`/`<font face>` 태그 실사용, 완벽하지 않은 정렬 허용.

## 톤 & 카피
- 20대 후반 남성, 다크판타지 온라인게임 팬. 담백한 존댓말, 가끔 신세한탄 섞인 일기 어투.
- 배너모음, 자동재생 BGM 표시, 방문자 카운터(LCD풍 검정+보라/청록 숫자) 등 시대 특유의 장치 포함.

## 알려진 제약
- 이미지/사진/BGM 실파일 없음 — 모두 자리표시자.
- 편집·로그인·방명록 등은 UI만 존재("준비중입니다" 알림).
